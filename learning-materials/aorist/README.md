# Supplied aorist learning material

`bulgarian_aorist_40.json` is the original user-supplied UTF-8 learning file,
preserved without content edits. SHA-256:
`AF92873C06A36C81973206CC24808D01E1E9CC2CDACCE66225F92F095C521E33`.

Format `bulgariantrainer.aorist`, format version 1, source dataset
`bg-aorist-core-40`, source revision 1, created 2026-11-17. It contains 40 verbs,
six person slots each and 240 explicitly stored accepted answers. Both aspects
are represented (11 imperfective, 29 perfective). The two reflexive paradigms
retain final `се` in isolated answers.

The file's source labels, URLs and checked dates are supplied provenance, not
independent linguistic review by this application. Its `вземам` entry is labelled
`2_ih` despite storing `вземах` forms; this is preserved with a nonblocking import
warning. Teaching labels do not generate conjugations or describe CEFR levels.

Nothing imports automatically. See [AORIST_CONTENT.md](../../AORIST_CONTENT.md)
for the separate upload/preview/confirmation API and material-only export.
This JSON is not a database backup and contains no learning progress.
